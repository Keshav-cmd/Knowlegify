Knowlegify // Research Terminal

«Connecting innovators and researchers worldwide.»

Knowlegify is a terminal-styled social learning and research platform designed to help students, innovators, and researchers discover knowledge, organize research resources, track learning progress, and build consistent study habits.

The platform combines a command-line-inspired interface with modern learning tools, creating an engaging environment for research and self-learning.

---

🚀 Features

1. Research Library

- Browse research resources by topic.
- Explore research papers, articles, books, and reports.
- Access trusted external research platforms.
- Discover experiments, simulations, patents, and scientific projects.

2. Personalized Dashboard

- Track research points.
- Monitor daily learning streaks.
- View daily objectives and progress.
- Access recommended learning resources.

3. Explore Library

- Discover educational and research materials.
- Navigate different knowledge categories.
- Find resources for learning and innovation.

4. My Research

- Organize your research activities.
- Keep track of saved resources.
- Manage your personal research collection.

5. Quizzes

- Test your knowledge.
- Practice concepts through quizzes.
- Improve your understanding of different subjects.

6. Leaderboard

- Explore top researchers.
- Compare research points.
- Encourage consistent learning and participation.

7. Focus Session

- Built-in productivity timer.
- Choose between 15, 25, and 50-minute sessions.
- Earn research points for completed focus sessions.

8. Terminal Console

- Command-line-inspired interaction.
- Keyboard shortcuts for navigation.
- Quick access to search and platform commands.
- Theme customization through terminal commands.

9. Additional Features

- Notification drawer.
- Research uploads.
- User profile and statistics.
- Data export and reset options.
- Multiple interface themes.
- Responsive interface design.

⚙️ Getting Started

Prerequisites

You need:

- A modern web browser.
- A code editor such as Visual Studio Code.
- The project files ("index.html", "styles.css", and "app.js").

Installation

1. Clone the repository

git clone https://github.com/your-username/knowlegify.git

2. Navigate to the project directory

cd knowlegify

3. Open the project

Open "index.html" in your browser.

Alternatively, use the Live Server extension in Visual Studio Code for local development.

🎨 Design Philosophy

Knowlegify follows a terminal-inspired visual design philosophy.

Key design elements include:

- Dark, terminal-style interface.
- Green-themed visual identity.
- Monospaced typography.
- Minimalist navigation.
- Command-line-inspired interactions.
- Research-focused dashboard.
- Responsive layouts.

The goal is to make research and learning feel organized, interactive, and engaging.
