**Discover research. Organize what you learn. Build a lasting learning habit.**

Knowlegify is a terminal-inspired learning and research platform for students, researchers, innovators, and lifelong learners. It brings resource discovery, personal research organization, interactive quizzes, focus sessions, and learning progress tracking into one responsive interface.

Use Knowlegify to explore educational resources, save material for later, test your understanding, and make time for focused study—all in a distinctive, command-line-inspired environment.

> **Our vision:** Create an interconnected learning environment where curiosity drives discovery and knowledge has no boundaries.

## Features

### Research library and discovery

- Browse educational and research resources across knowledge domains.
- Explore papers, articles, books, reports, experiments, and simulations.
- Follow links to established research repositories and learning platforms.
- Find material and inspiration for independent study and research ideas.

### Personal learning dashboard

- Review research points, learning progress, and study streaks.
- Keep track of daily objectives and recommended resources.
- View personal research and learning statistics.

### My Research

- Save useful resources to a personal collection.
- Keep research materials and learning interests organized.

### Quizzes and leaderboard

- Practice concepts with interactive, subject-based quizzes.
- Reinforce previously learned material.
- See leaderboard rankings and compare research points.

### Focus sessions

- Choose a 15-, 25-, or 50-minute study session.
- Use structured intervals to build consistent study habits.
- Earn research points for completed sessions.

### Terminal-inspired interface

- Use keyboard shortcuts and quick commands to navigate.
- Search for resources and switch interface themes through the terminal console.
- Work in a responsive, dark interface with a green visual identity and monospaced typography.

### More tools

- Notifications, research uploads, user profiles, and statistics.
- Data export and reset options.
- Multiple interface themes and responsive layouts.

> Features and data persistence can vary by version. Check the current application for what is available.

## Getting started

### Requirements

- A modern web browser.
- Git (for cloning the repository).
- A code editor such as Visual Studio Code (optional).

### Run locally

```bash
git clone https://github.com/keshav-cmd/Knowlegify.git
cd Knowlegify
```

Open `index.html` in a browser, or run the folder with a local development server such as the Visual Studio Code **Live Server** extension.
