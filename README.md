## 📖 About Knowlegify

**Knowlegify** is a terminal-inspired social learning and research platform built to empower students, innovators, researchers, and lifelong learners.

It brings research discovery, knowledge organization, productivity tracking, and interactive learning together in a unified environment.

Inspired by the simplicity of command-line interfaces and the possibilities of modern technology, Knowlegify aims to make independent learning and scientific exploration more accessible, engaging, and organized.

Whether you're exploring scientific literature, managing research materials, testing your knowledge, or building consistent learning habits, Knowlegify provides a dedicated space for your intellectual journey.

> **Our vision:** Create an interconnected learning environment where curiosity drives discovery and knowledge has no boundaries.

## ⚡ Getting Started

Get your local copy of Knowlegify running in a few simple steps.

### Prerequisites

You'll need:

- A modern web browser.
- Git installed on your system.
- A code editor such as Visual Studio Code.

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/your-username/knowlegify.git
```

**2. Navigate to the project directory**

```bash
cd knowlegify
```

**3. Launch the application**

Open `index.html` in your preferred browser.

Alternatively, use the **Live Server** extension in Visual Studio Code for a better local development experience.

## 🎨 Design Philosophy

Knowlegify follows a **terminal-inspired design philosophy**, combining the aesthetics of traditional command-line environments with modern web application functionality.

### Core Design Principles

- **Terminal Aesthetics:** A dark interface inspired by command-line environments.
- **Green Visual Identity:** A distinctive green-themed visual language.
- **Monospaced Typography:** A technical and research-oriented appearance.
- **Minimalist Navigation:** Simple navigation with reduced visual clutter.
- **Keyboard Accessibility:** Command-line-inspired interactions and shortcuts.
- **Research-Centric Experience:** An interface designed around knowledge discovery.
- **Responsive Design:** Adaptability across different screen sizes.

The objective is simple: make the process of learning, researching, and exploring knowledge feel engaging and intuitive.
